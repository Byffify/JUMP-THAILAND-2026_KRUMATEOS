The Problem

The Solution

พิมพ์คำสั่ง 1 บรรทัด — ได้สื่อครบ ใน 5–10 นาที

KruMate OS คือ AI Teaching Studio สำหรับครูไทย: กรอก Prompt สั้นๆ แล้วสร้างสื่อการสอนได้ 6 ประเภทในขั้นตอนเดียว

ตัวอย่าง: "สร้างบทเรียนวิทยาศาสตร์ ป.6 เรื่องระบบนิเวศ"  →  แผนการสอน · ใบงาน · แบบทดสอบ · สไลด์ · เกณฑ์การประเมิน · กิจกรรมในชั้นเรียน

Roadmap

ต่อยอดจากฐานที่ พร้อมขยาย

  • ✓ ระบบล็อกอินจริงปัจจุบันเป็น Auth Gate แบบจำลอง — เตรียมพร้อมให้เชื่อม OAuth/SSO
  • ✓ Cloud Sync & แชร์สื่อแชร์แผน/ใบงานระหว่างครูทั้งโรงเรียน
  • ✓ Export .docx / .pptxส่งออกไฟล์ที่ครูใช้จริงในห้อง
  • ✓ สร้างหลายประเภทจาก 1 PromptBundle: แผน + ใบงาน + ข้อสอบในครั้งเดียว
  • ✓ รองรับหลักสูตร / ตัวชี้วัดสุจริตจับเนื้อหาตรงหลักสูตร สพฐ.
  • ✓ Template Marketplaceชุมชนครูแชร์เทมเพลตสวยๆ กันเอง
  • ✓ Offline ModeMock ทำงานได้แม้ไม่มีอินเทอร์เน็ต
  • ✓ แพ็กเกจรายโรงเรียนAdmin dashboard + รายงานเวลาที่ประหยัดรวม
