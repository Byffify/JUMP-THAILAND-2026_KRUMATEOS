1 KruMate OS คืออะไร

KruMate OS คือ AI Teaching Studio สำหรับครูไทย — แพลตฟอร์มที่ให้ครูพิมพ์ Prompt (คำสั่ง) สั้นๆ หนึ่งบรรทัด แล้ว AI จะสร้างสื่อการสอนสำเร็จรูปให้ในชั่วโมงทำงาน ไม่ใช่ระบบ LMS, ERP, หรือระบบบริหารนักเรียน

2 ปัญหาที่แก้ (Problem)

ครูไทยใช้เวลากับงานเตรียมสื่อทุกวัน: แผนการสอน · ใบงาน · แบบทดสอบ · สไลด์ · เกณฑ์การประเมิน · กิจกรรม เวลาที่หายไปเหล่านี้ถูกขโมยจากสิ่งที่สำคัญกว่า — การตั้งใจสอน การดูแลนักเรียน การออกแบบกิจกรรม เราเน้นแก้ "เวลาเตรียมสื่อ" ไม่ใช่สร้างระบบบริหารอีกตัว

3 วิธีใช้ / หน้าในแอป (ตัวจริงตอนนี้)

App เป็น SPA สมัยใหม่ (React) ประกอบด้วยหน้าหลัก 6 หน้า + ระบบสนับสนุน:

หน้าบทบาทรายละเอียดฟีเจอร์
Dashboardหน้าหลักกล่อง Prompt ใหญ่สำหรับค้นหา + Quick Create (6 ประเภท) + สถิติเวลาที่ประหยัด + Recent + AI Suggestions (5 ข้อ อัปเดตตามภาษา)
Generatorเครื่องมือสร้างพิมพ์ Prompt → เลือกระดับชั้น 13 ระดับ (อนุบาล/ป.1–ป.6/ม.1–ม.6) → วิชา 12 วิชา → ประเภท 1 อย่าง (6 ประเภท) → Generate
Content Viewหน้าดูเนื้อหาพรีวิวเต็มจอ สถานะบันทึก/ยังไม่บันทึก + คัดลอก/พิมพ์/ดาวน์โหลด/บันทึกเป็นรูปภาพ
Libraryคลังเนื้อหาค้นหา (ชื่อ/วิชา/Prompt) + กรองหมวดหมู่/วิชา + ลบ + เปิดดู (ข้อมูลจาก localStorage)
AI Assistantผู้ช่วยแชทแชทถามไอเดียบทเรียน ใบงาน ข้อสอบ วิธีจัดโครงสร้างชั้นเรียน (ไม่บันทึกประวัติ)
Support Centerศูนย์ช่วยเหลือคู่มือครู + FAQ พร้อมช่องค้นหา · บทความแต่ละอันเป็นหน้าแยก /support/guide/:id
เส้นทางผู้ใช้มาตรฐาน: Dashboard → พิมพ์ Prompt → เลือกประเภท/ระดับ/วิชา → Generate → Preview → บันทึก/ส่งออก

4 ฟีเจอร์หลักโดยละเอียด

4.1 การสร้างเนื้อหา (Generator)

  • 6 ประเภทผลงาน: แผนการสอน · ใบงาน · แบบทดสอบ · สไลด์ · เกณฑ์การประเมิน · กิจกรรมในชั้นเรียน
  • เลือกได้ทีละ 1 ประเภท (radio-style) + ระดับชั้น 13 ระดับ + วิชา 12 วิชา
  • 2 โหมดการสร้าง:
    • โหมดอิสระ: พิมพ์ Prompt อะไรก็ได้
    • โหมดเทมเพลต: กรอกฟอร์ม (หัวข้อ ระยะเวลา/คาบ จุดประสงค์ หมายเหตุ) → ระบบประกอบ Prompt ให้อัตโนมัติ แก้ไขต่อได้ มี preview
  • ตั้งค่าข้อสอบ: จำนวนข้อ 5–30 ข้อ · ประเภทคำถาม ปรนัย/ถูก-ผิด/ข้อเขียนสั้น

4.2 การค้นหา (Dashboard + Library)

ค้นหาในคลังด้วยชื่อเรื่อง/วิชา/Prompt · ประวัติการค้นหา 10 รายการล่าสุด + ล้างทั้งหมด · Quick Create ไปหน้า Generator พร้อมประเภทที่เลือก

4.3 การส่งออก (Export)

  • คัดลอก ลงคลิปบอร์ด
  • พิมพ์ (print-friendly layout)
  • ดาวน์โหลด เป็นไฟล์ข้อความ
  • บันทึกเป็นรูปภาพ PNG — ผ่าน html2canvas ใช้แชร์ได้

4.4 ระบบ AI

  • Gemini API ผ่าน Serverless Proxy (Vercel Function) — Key เก็บฝั่งเซิร์ฟเวอร์เท่านั้น ไม่รั่วลง client bundle
  • Fallback เป็น Mock Data อัตโนมัติ เมื่อ Gemini ไม่พร้อม — การเดโมไม่สะดุด
  • interface เดียว (API.*) สำหรับ generate / suggestions / assistant

4.5 ระบบข้อมูล (Local First)

localStorage เก็บ: คลังเนื้อหา, metrics, ข้อมูลผู้ใช้, ประวัติค้นหา · Live store (หน่วยความจำ session) สำหรับเนื้อหาที่ยังไม่ได้บันทึก · ไม่ต้องมี backend สำหรับเดโม/ใช้งานส่วนตัว

4.6 ภาษา & 4.7 ระบบสนับสนุน

  • ไทย/อังกฤษ ครบทุกหน้า ปุ่มสลับภาษามุมขวาบน (i18n กลางเดียว)
  • Support Center: Tab คู่มือครู + FAQ · หมวด guide: เริ่มต้น/ประเภทผลงาน/คลัง&ส่งออก/ผู้ช่วย&เทมเพลต · แต่ละหมวดเป็น card หัวข้อเป็นลิงก์→หน้าแยก · FAQ 6 คำถาม 2 ภาษา · ช่องค้นหากรองทันที

5 ตัวชี้วัดความสำเร็จ (KPI)
  • Primary KPI: Hours Saved Per Teacher — ชั่วโมงที่ประหยัดได้ต่อครู
  • Materials Generated — จำนวนสื่อที่สร้าง
  • Hours Saved — ชั่วโมงที่คืนให้ครู (คำนวณ ~0.75 ชม./สื่อ)
  • Weekly Active Teachers · Generation Success Rate (มั่นคงด้วย mock fallback)
6 เส้นทางไอเดียตั้งแต่ต้น (Journey)
  1. นิยามโจทย์ (requirement.md) — AI Content สร้าง 6 ประเภท ลดเวลา 2–3 ชม. → 5–10 นาที ไม่ใช่ LMS/ERP วัดด้วย "เวลาที่คืนให้ครู"
  2. ตั้งฐานสถาปัตยกรรม — Vanilla JS SPA → React 18 + Vite + Tailwind ครบทุกหน้า (parity ตรวจเทียบหน้าตา/ฟีเจอร์)
  3. เชื่อม AI จริง — Lesson + Quiz Generation ด้วย Gemini API + prompt แยกตามประเภท
  4. สเกลตัวเลือก — ระดับชั้น 13 ระดับ + วิชา 12 วิชา + single-type
  5. คุณค่าครบวงจร — export (copy/print/download/รูปภาพ) + สร้างภาพได้ + Content View เฉพาะ
  6. ปรับประสบการณ์ — โหมดเทมเพลต + UI/i18n สองภาษา + โลโก้ KruMate
  7. ความปลอดภัย — Gemini หลัง Serverless Proxy กัน key รั่ว
  8. ปิดท้ายด้วย Trust — Support Center (คู่มือครู + FAQ) → ปรับนำทางเข้า navbar
ไอเดียใหญ่ตลอดมา: "ทำอะไรทีละชั้น แล้วค่อยๆ เพิ่มคุณค่า" — ถามเสมอว่า ครูได้อะไร? และ ปลอดภัยไหม?
7 Roadmap / แนวทางต่อยอด
  • ใกล้: ล็อกอินจริง (Auth Gate จำลอง → OAuth/SSO) · สร้างหลายประเภทจาก 1 Prompt (bundle) · Export .docx/.pptx
  • กลาง: Cloud Sync + แชร์สื่อ · รองรับหลักสูตร/ตัวชี้วัด (สพฐ.) · Admin Dashboard + รายงาน · แพ็กเกจรายโรงเรียน/เขต
  • ไกล: Template Marketplace · Offline Mode · โมเดลภาษาไทยเฉพาะทาง (fine-tune)
8 สิ่งที่ทำให้เราต่าง
  • เจาะจงคนไทย: ระดับชั้น 13 ระดับ วิชาตรงหลักสูตร ไทย/อังกฤษ ตั้งแต่แรก
  • เรียบง่ายสุด: 1 Prompt → สื่อ 6 ประเภท → บันทึก/ส่งออก ทางเดียวจบ
  • Local-first: ไม่ต้องตั้ง server ข้อมูลอยู่กับครู
  • ปลอดภัยโดยดีไซน์: ไม่เก็บ key ในเว็บ + fallback กันเดโมพัง
  • แคร์ครู: สถิติเน้น "เวลาที่คืนให้ครู" + คู่มือช่วยเหลือครบ
