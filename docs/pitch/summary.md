## 1. KruMate OS คืออะไร

**KruMate OS คือ AI Teaching Studio สำหรับครูไทย** — แพลตฟอร์มที่ให้ครูพิมพ์ Prompt (คำสั่ง) สั้นๆ หนึ่งบรรทัด แล้ว AI จะสร้างสื่อการสอนสำเร็จรูปให้ในชั่วโมงทำงาน ไม่ใช่ระบบ LMS, ERP, หรือระบบบริหารนักเรียน

**ปรัชญาหลัก:** "We Don't Replace Teachers. We Give Their Time Back."
เราไม่ได้มาแทนครู เราเอาเวลากลับคืนให้ครู

**เป้าหมาย:** ลดเวลาทำสื่อจาก 2–3 ชั่วโมง ต่อบทเรียน → เหลือ 5–10 นาที
- ลดเวลาเตรียมการสอน 50–70%
- คืนเวลา 5–7 ชั่วโมงต่อครูต่อสัปดาห์

## 2. ปัญหาที่แก้ (Problem)

ครูไทยใช้เวลากับงานเตรียมสื่อเป็นจำนวนมากทุกวัน:
- **แผนการสอน** — จุดประสงค์ สื่อ ขั้นตอน ต้องคิดและเขียนทุกครั้ง
- **ใบงาน** — ต้องออกแบบแบบฝึกหัดให้เหมาะกับชั้นเรียน
- **แบบทดสอบ** — ปรนัย/ถูกผิด/ข้อเขียน ต้องออกและตรวจ
- **สไลด์นำเสนอ** — ต้องสร้างโครงเนื้อหาและดีไซน์
- **เกณฑ์การประเมิน** — ต้องออกแบบ rubric ให้สอดคล้อง

เวลาที่หายไปเหล่านี้ ถูกขโมยจากสิ่งที่สำคัญกว่า: **การตั้งใจสอน การดูแลนักเรียน การออกแบบกิจกรรม** เราเน้นแก้ "เวลาเตรียมสื่อ" ไม่ใช่สร้างระบบบริหารอีกตัว

## 3. วิธีใช้ / หน้าในแอป (ตัวจริงตอนนี้)

App เป็น SPA สมัยใหม่ (React) ประกอบด้วยหน้าหลัก 6 หน้า + ระบบสนับสนุน:

| หน้า | บทบาท | รายละเอียดฟีเจอร์ |
|---|---|---|
| **Dashboard** | หน้าหลัก | กล่อง Prompt ใหญ่สำหรับค้นหา + Quick Create (สร้างด่วน 6 ประเภท) + สถิติเวลาที่ประหยัดได้ + Recent Creations + AI Suggestions (ไอเดียจาก AI 5 ข้อ อัปเดตตามภาษา) |
| **Generator** | เครื่องมือสร้าง | พิมพ์ Prompt → เลือกระดับชั้น (อนุบาล/ป.1–ป.6/ม.1–ม.6 = 13 ระดับ) → เลือกวิชา (12 วิชา) → เลือกประเภท 1 อย่าง (6 ประเภท) → Generate |
| **Content View** | หน้าดูเนื้อหา | พรีวิวผลลัพธ์เต็มจอ ดูสถานะบันทึก/ยังไม่บันทึก + ปุ่ม คัดลอก/พิมพ์/ดาวน์โหลด/บันทึกเป็นรูปภาพ |
| **Library** | คลังเนื้อหา | ค้นหา (ชื่อ/วิชา/Prompt) + กรองหมวดหมู่ + กรองวิชา + ลบ + เปิดดู · ประวัติดึงมาจาก localStorage |
| **AI Assistant** | ผู้ช่วยแชท | แชทถามไอเดียบทเรียน ใบงาน ข้อสอบ วิธีจัดโครงสร้างชั้นเรียน (ไม่บันทึกประวัติ) |
| **Support Center** | ศูนย์ช่วยเหลือ | คู่มือครู (Teacher's Guide) + FAQ พร้อมช่องค้นหา · บทความแต่ละอันเป็นหน้าแยก `/support/guide/:id` |

**เส้นทางผู้ใช้มาตรฐาน:**
Dashboard → พิมพ์ Prompt → เลือกประเภท/ระดับ/วิชา → Generate → Preview → บันทึก/ส่งออก

## 4. ฟีเจอร์หลักโดยละเอียด

### 4.1 การสร้างเนื้อหา (Generator)
- **6 ประเภทผลงาน:** แผนการสอน (Lesson Plan), ใบงาน (Worksheet), แบบทดสอบ (Quiz), สไลด์ (Slides), เกณฑ์การประเมิน (Rubric), กิจกรรมในชั้นเรียน (Classroom Activity)
- **เลือกได้ทีละ 1 ประเภท** (radio-style) พร้อมตัวเลือก **ระดับชั้น 13 ระดับ** และ **วิชา 12 วิชา**
- **2 โหมดการสร้าง:**
  - **โหมดอิสระ (Free mode):** พิมพ์ Prompt อะไรก็ได้
  - **โหมดเทมเพลต (Template mode):** กรอกฟอร์ม (หัวข้อ ระยะเวลา/คาบ จุดประสงค์ หมายเหตุ) → ระบบประกอบ Prompt ให้อัตโนมัติ แก้ไขต่อได้ และมี preview ก่อนส่ง
- **ตั้งค่าข้อสอบ:** จำนวนข้อ 5–30 ข้อ, ประเภทคำถาม ปรนัย/ถูก-ผิด/ข้อเขียนสั้น (เลือกอย่างน้อย 1 ประเภท)

### 4.2 การค้นหา (Dashboard + Library)
- ค้นหาในคลัง: ชื่อเรื่อง, วิชา, หรือ Prompt เดิม
- ประวัติการค้นหา (10 รายการล่าสุด) + ล้างทั้งหมด
- Popular/แนะนำคำค้น
- Quick Create: ไปหน้า Generator พร้อมประเภทที่เลือกไว้เลย

### 4.3 การส่งออก (Export)
- **คัดลอก** ลงคลิปบอร์ด
- **พิมพ์** (print-friendly layout ผ่าน `#print-root`)
- **ดาวน์โหลด** เป็นไฟล์ข้อความ
- **บันทึกเป็นรูปภาพ (PNG)** — ผ่าน html2canvas ได้ภาพสวยใช้แชร์ได้

### 4.4 ระบบ AI
- **Gemini API** เป็นตัวหลัก ผ่าน **Serverless Proxy (Vercel Function)** — Key เก็บฝั่งเซิร์ฟเวอร์เท่านั้น ไม่รั่วลง client bundle
- มี **Fallback เป็น Mock Data อัตโนมัติ** เมื่อ Gemini ไม่พร้อม (ไม่ตั้ง key / offline) — การเดโมไม่สะดุด
- Extension-points: `generate` / `suggestions` / `assistant` ทั้งหมดผ่าน interface เดียว (`API.*`)

### 4.5 ระบบข้อมูล (Local First)
- **localStorage** เก็บ: คลังเนื้อหา, metrics, ข้อมูลผู้ใช้, ประวัติค้นหา
- **Live store** (หน่วยความจำของ session) สำหรับเนื้อหาที่ยังไม่ได้บันทึก
- ไม่ต้องมี backend สำหรับเดโม/ใช้งานส่วนตัว

### 4.6 ภาษา
- **ไทย / อังกฤษ** ครบทุกหน้า มีปุ่มสลับภาษา มุมขวาบน (i18n system กลางเดียว)

### 4.7 ระบบสนับสนุน (Support Center)
- Tab Teacher's Guide + FAQ
- **หมวด guide:** เริ่มต้นใช้งาน / ประเภทผลงาน / คลัง & ส่งออก / ผู้ช่วย & โหมดเทมเพลต
- แต่ละหมวดเป็น **card** หนึ่งใบ หัวข้อในนั้นเป็นลิงก์ธรรมดา → เปิดเป็นหน้าแยก
- FAQ หมวด: การสร้างเนื้อหา / เทคนิค & ส่งออก (6 คำถาม 2 ภาษา)
- ช่องค้นหาที่กรองข้ามบทความและ FAQ ได้ทันที

## 5. เทคโนโลยี / สถาปัตยกรรม

```
React 18 + Vite 5          SPA เร็ว, hot reload, tree-shaking
Tailwind CSS 3             design system + responsive
react-router-dom 6         HashRouter (รองรับ deploy ง่ายทุกที่)
Gemini API                 สร้างเนื้อหา AI จริง
html2canvas                export ภาพ PNG
Vercel Serverless          proxy สำหรับ Gemini (protects key)
```

**โครงสร้างโค้ด:** (ตาม folder `src/`)
- `pages/` — หน้าแต่ละหน้า
- `components/` + `components/support/` — ส่วนประกอบ UI
- `context/` — I18n, Toast, Modal, App (ผู้ใช้ + สถานะร่วม)
- `services/` — api.js (Gemini+fallback), geminiService.js, store.js, i18n.js
- `data/` — types.js (ประเภท/ระดับ/วิชา), generator.js (mock), support.js (เนื้อหา support)

**Design system:** สีแบรนด์ Romantic orange `#FAAA48` · Peach glow `#FFDDAC` · Chocolatemelange `#2F0F03` · cream `#FFFDF9` — แรงบันดาลใจจาก Fastwork (สะอาด, responsive, minimal, เร็ว)

## 6. ตัวชี้วัดความสำเร็จ (KPI)

- **Primary KPI: Hours Saved Per Teacher** — ชั่วโมงที่ประหยัดได้ต่อครู
- Materials Generated — จำนวนสื่อที่สร้าง
- Hours Saved — ชั่วโมงที่คืนให้ครู (คำนวณ ~0.75 ชม. ต่อสื่อ)
- Weekly Active Teachers — ครูที่ใช้รายสัปดาห์
- Generation Success Rate — อัตราการสร้างสำเร็จ (มั่นคงด้วย mock fallback)

## 7. เส้นทางไอเดียตั้งแต่ต้น (Journey จากประวัติ commit)

1. **นิยามโจทย์** (`requirement.md`) — เขียน requirement ชัดเจน: เน้น AI Content สร้าง 6 ประเภท ลดเวลา 2–3 ชม. → 5–10 นาที, ไม่ใช่ LMS/ERP, วัดผลด้วย "เวลาที่คืนให้ครู"
2. **ตั้งฐานสถาปัตยกรรม** — จาก Vanilla JS SPA → ย้ายทั้งหมดเป็น **React 18 + Vite + Tailwind** (migration ครบทุกหน้า ตรวจ parity ว่าหน้าตา/ฟีเจอร์เดิมยังครบ)
3. **เชื่อม AI จริง** — เพิ่มหน้า Lesson + Quiz Generation ด้วย **Gemini API** + ระบบ prompt แยกตามประเภท
4. **สเกลตัวเลือก** — ระดับชั้น (K, ป.1–ป.6, ม.1–ม.6) + วิชา 12 วิชา + selected-type ตัวเดียว
5. **คุณค่าครบวงจร** — export utilities (copy/print/download/รูปภาพ), สร้างภาพได้, หน้า Content View เฉพาะ
6. **ปรับประสบการณ์** — โหมดเทมเพลต (กรอกฟอร์มแทน prompt ฟรี) + ปรับ UI/i18n สองภาษา + โลโก้ KruMate
7. **ความปลอดภัย** — ย้าย Gemini ไปหลัง **Serverless Proxy** ป้องกัน key รั่วลงเว็บ/คลังหน้าใหม่
8. **ปิดท้ายด้วย Trust** — **Support Center** (คู่มือครู + FAQ) ให้ครูเริ่มใช้เองได้ → ปรับนำทาง เข้า navbar

> ไอเดียใหญ่ตลอดมา: "ทำอะไรทีละชั้น แล้วค่อยๆ เพิ่มคุณค่า" — ถามเสมอว่า *ครูได้อะไร?* และ *ปลอดภัยไหม?*

## 8. Roadmap / แนวทางต่อยอด (ไอเดียเพิ่ม)

**ใกล้ (ยกระดับประสบการณ์):**
- ระบบล็อกอินจริง (ปัจจุบันเป็น Auth Gate จำลอง) — เตรียมรองรับ OAuth/SSO
- สร้างหลายประเภทจาก 1 Prompt (bundle: แผน + ใบงาน + ข้อสอบ ในครั้งเดียว)
- Export เป็น .docx / .pptx (ไฟล์ที่ครูใช้จริงในห้อง)

**กลาง (scale + ครบวงจร):**
- Cloud Sync + แชร์สื่อระหว่างครูทั้งโรงเรียน
- รองรับหลักสูตร / ตัวชี้วัด (ตรงหลักสูตร สพฐ.)
- Admin Dashboard สำหรับโรงเรียน + รายงานเวลาที่ประหยัดรวม
- แพ็กเกจรายโรงเรียน/รายเขต

**ไกล (community & ecosystem):**
- Template Marketplace — ชุมชนครูแชร์เทมเพลตสวยๆ กันเอง
- Offline Mode — ใช้งาน mock ได้แม้ไม่มีอินเทอร์เน็ต
- โมเดลภาษาไทยเฉพาะทาง (fine-tune) เพื่อคุณภาพวิชาการไทยดียิ่งขึ้น

## 9. สิ่งที่ทำให้เราต่าง (Summary ฉบับกระชับ for deck)

- **เจาะจงคนไทย:** ระดับชั้น 13 ระดับ วิชาตรงหลักสูตร ภาษาไทย/อังกฤษ ตั้งแต่แรก
- **เรียบง่ายสุด:** 1 Prompt → สื่อ 6 ประเภท → บันทึก/ส่งออก ทางเดียวจบ
- **Local-first:** ไม่ต้องตั้ง server การใช้งานส่วนตัว ข้อมูลอยู่กับครู
- **ปลอดภัยโดยดีไซน์:** ไม่เก็บ key ไว้ในเว็บ, มี fallback กันเดโมพัง
- **แคร์ครู:** สถิติเน้น "เวลาที่คืนให้ครู" + มีคู่มือช่วยเหลือครบ

> **One-liner:** KruMate OS เป็น AI Teaching Studio ที่ช่วยครูไทยสร้างแผนการสอน ใบงาน แบบทดสอบ และสื่อการสอนจากคำสั่งสั้นๆ เพียงบรรทัดเดียว ลดเวลาการเตรียมเนื้อหา และให้ครูมุ่งเน้นที่การสอนแทนการสร้างเนื้อหา
